# Lingua Studio

Тренажёр иностранных языков (немецкий, английский, польский…) на чистом JS + Vite.

## Режимы

| Режим | Что делает |
| --- | --- |
| 🧩 Пазл предложений | Собрать фразу из слов (клик или перетаскивание), слова раскрашены по частям речи |
| 🔤 Спеллер слов | Собрать слово по буквам — мышкой или с клавиатуры |
| 🔗 Пары слов | Соединить слово с переводом или с английским определением (поле `definition`), раунды по 6 слов |
| ❓ Вопросы к тексту | Вопросы на понимание текста с вариантами ответа (`questions` в JSON урока); если их нет — автоматически «выберите перевод» и «какое слово пропущено» |
| 🎧 Диктант на слух | Прослушать фразу и вписать пропущенные слова; 3 уровня сложности, медленное воспроизведение, подсказки, кнопки ä/ö/ü/ß |
| 📖 Умный ридер | Текст урока с озвучкой по строкам, переводом и словарём по клику на слово |
| 🔬 Текст-лаборатория | Разбор любого текста и сохранение его как урока в свою учебную зону |

В пазле, спеллере, парах слов, вопросах и диктанте задания идут **по кругу, пока не будут решены правильно**: верный ответ убирает задание из очереди, ошибочное возвращается в конец (с пометкой «🔁 повтор»). В парах слов ошибки собираются в отдельный раунд повторения.

Прогресс урока (верно решённые задания), статистика и тема (светлая/тёмная) хранятся в `localStorage`.

## Ссылки на урок

Адрес страницы всегда отражает текущий выбор: **профиль → курс → урок → режим**, его можно сохранить в закладки или отправить (кнопка 🔗 рядом с выбором урока копирует ссылку):

```
https://maks-t.github.io/lingua-trainer/?profile=dad&course=en-b1&unit=en-b1-ted-smith&mode=quiz
```

- `profile` — id профиля из `catalog.json` (`dad`, `son`, `pavel`);
- `course` — `<язык>-<уровень>` для курсов каталога (`de-a1`, `en-b1`) или id своей зоны;
- `unit` — id урока;
- `mode` — `puzzle`, `speller`, `match`, `quiz`, `dictation`, `reader`, `analyzer`.

Свои уроки из «Текст-лаборатории» хранятся в браузере, поэтому ссылка на них работает только на том же устройстве.

## Запуск

```bash
pnpm install
pnpm dev          # локальный сервер
pnpm build        # сборка в dist/
```

Пуш в `main` собирает проект и публикует его в ветку `gh-pages` (GitHub Actions).
Ручной деплой: `pnpm deploy:gh-pages`.

## Данные

Всё статическое лежит в `public/` и копируется в сборку как есть:

- `public/data/catalog.json` — профили, языки, уровни и список уроков;
- `public/data/units/<lang>/<level>/*.json` — уроки;
- `public/audio/...` — озвучка (если mp3 нет, используется синтез речи браузера).

Формат вопроса к тексту:

```json
{ "id": "q1", "question": "Woher kommt Sarah?", "ru": "Откуда родом Сара?",
  "answer": "Aus Deutschland", "options": ["Aus Deutschland", "Aus Österreich", "Aus Russland"],
  "ref": "t4", "audio": "audio/de/a1/unit_01/q1.mp3" }
```

`ref` — id абзаца из `text`, который подсвечивается после ответа.

Видео урока (YouTube) — показывается в боковой панели и в «Умном ридере», открывается во встроенном плеере:

```json
"video": { "youtube": "iKHTawgyKWQ", "start": 0, "title": "Larry Smith: Why you will fail to have a great career" }
```

Для своих уроков ссылку на YouTube можно указать при сохранении в «Текст-лаборатории».

## Озвучка

```bash
pip install -r requirements.txt
python scripts/generate_audio.py                                      # все уроки
python scripts/generate_audio.py public/data/units/de/a1/unit_01_intro.json  # один урок
```

Уже существующие mp3 скрипт пропускает, так что после добавления вопросов или слов его можно просто запустить снова.
